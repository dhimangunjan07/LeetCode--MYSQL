# LeetCode - MySQL Solutions 🗄️

A collection of my **MySQL solutions to LeetCode SQL problems**, organized by difficulty to practice SQL, DBMS concepts, and database problem-solving for technical interviews.

## 📌 About

This repository contains my solutions to various **LeetCode SQL problems** using MySQL.

The problems are organized into three difficulty levels:

- 🟢 **Easy** – Basic SQL queries and database operations
- 🟡 **Medium** – Intermediate SQL logic, joins, subqueries, and aggregations
- 🔴 **Hard** – Advanced SQL queries and complex database problems
